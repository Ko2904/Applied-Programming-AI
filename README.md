# Applied Programming & AI

This repository contains three independent learning projects exploring web
data, interactive applications, and browser extensions.

## Projects

- [Books to Scrape](./books-to-scrape/README.md) — a catalogue scraper and
  Streamlit storefront.
- [ScreenScope](./tvmaze-api/README.md) — a Streamlit TV and film explorer.
- [New Tab Dashboard](./momentum-dash-replica/README.md) — a Chrome new-tab
  extension with personal productivity widgets.

Choose a project and follow its README for setup, usage, dependencies, and
limitations.
